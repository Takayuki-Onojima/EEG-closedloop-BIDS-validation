# The phase analysis and the two figures read the BrainVision recordings through
# MNE-Python, so that channel names, units and the reference scheme come from the

# reopen the data. MNE also supplies the montage and the topographic plotting
# used by Figure 3. MNE-BIDS and pandas are not required.
#
# Minimum versions are given so the code runs in an existing environment; the
# released outputs were produced with numpy 2.0.1, scipy 1.15.3,
# matplotlib 3.10.6 and mne 1.12.1 on Python 3.10.
